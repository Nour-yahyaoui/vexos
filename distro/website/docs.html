VexOS documentation

VexOS is a small Linux distribution built on Debian. This page covers installing it, using it, and building it yourself.

What is VexOS?

VexOS comes in two editions:

EditionWhat you getStatus
VexOS Desktop 1.0 A live ISO with the XFCE desktop, Firefox ESR, Python 3, Node.js and npm, git, and the full Debian apt package manager. Ready. Boots in VirtualBox.
VexOS Linux 1.0 A terminal-only system: bash, BusyBox, the vpk package manager, and vexpad. The whole system runs from memory. Working. The kernel build is still untested.

Most people want VexOS Desktop. The rest of this page is about it, unless it says otherwise.

Install in VirtualBox

You need VirtualBox 7 or newer, and about 10 GB of free disk space.

1. Download the ISO

Get vexos-desktop-1.0-amd64.iso from the download link or the releases page. Check it against the .sha256 file if one is published:

sha256sum vexos-desktop-1.0-amd64.iso

2. Create the virtual machine

  1. Click New. Set Type to Linux and Version to Debian (64-bit).
  2. Set memory to 4096 MB and processors to 2.
  3. Choose Do not add a virtual hard disk. The live system runs from the ISO.
  4. Open Settings > Storage. Under the optical drive, choose the ISO file.
  5. Open Settings > Display. Set Graphics Controller to VMSVGA and Video Memory to 128 MB.
  6. Optional: under Settings > System, tick Enable EFI if you want UEFI boot. BIOS works by default.

3. Boot

Start the VM. At the boot menu, press Enter on the default Live entry. The LightDM login screen appears. Log in as user with password live.

Changes are lost on reboot

The live system runs in memory. Files you save, packages you install, and settings you change are gone after a reboot. Put anything you want to keep on a shared folder or in a host file. An installer to disk is on the roadmap.

First steps

The desktop

  • Terminal: open it from the application menu.
  • Browser: Firefox ESR is in the application menu.
  • Sample files: the Desktop folder holds about-vexos.html, hello-web.html, and hello.py.
  • Admin rights: the user account has sudo. Use sudo for system changes.

Try the samples

  1. Double-click hello-web.html. It opens in Firefox and runs JavaScript. If the page says it works, JavaScript is running.
  2. Open a terminal in the Desktop folder and run: 
    python3 hello.py

Check the tools

python3 --version
node --version
npm --version
git --version
firefox-esr --version

Tutorials

Each tutorial works on a running VexOS Desktop session. Open a terminal first.

Tutorial 1: Your first Python project

Debian protects the system Python, so install project packages inside a virtual environment.

  1. Make a project folder and enter it: 
    mkdir -p ~/Desktop/myproject && cd ~/Desktop/myproject
  2. Create and activate a virtual environment: 
    python3 -m venv .venv
source .venv/bin/activate
  3. Install a package (this needs internet): 
    pip install requests
  4. Write app.py: 
    import requests
import sys
print("Python", sys.version.split()[0], "is working")
print("requests", requests.__version__)
  5. Run it: 
    python app.py

Run deactivate to leave the environment. Your environment stays in the folder, so the next session needs source .venv/bin/activate again.

Tutorial 2: A Node.js script

  1. Create a file called hello-node.js: 
    const os = require("os");
console.log("Hello from Node", process.version);
console.log("Running on", os.type(), os.arch());
  2. Run it: 
    node hello-node.js
  3. To use packages, start a project and install them: 
    npm init -y
npm install express

Tutorial 3: Install software with apt

The live system uses the Debian mirrors, so the whole Debian catalog is available.

sudo apt update
apt search htop
sudo apt install -y htop
htop

Packages installed this way last only for the current session.

Tutorial 4: Edit text with vexpad

vexpad is the small terminal editor included in VexOS. It is a lightweight wrapper around vi.

vexpad --help
vexpad ~/Desktop/notes.txt

Use the usual vi keys: press i to type, Esc to stop typing, then :wq and Enter to save and quit.

Tutorial 5: Make a web page

Copy Desktop/hello-web.html to Desktop/my-page.html and open it in Firefox. Edit it in vexpad and reload Firefox to see your changes. Everything runs locally, so no server is needed.

Build the ISO yourself

You can build the desktop ISO from the source. The build needs a Debian or Ubuntu machine with about 15 GB of free disk space and 4 GB of RAM. A Debian install under WSL works for building. It takes 30 to 90 minutes.

1. Download only the desktop folder

A sparse clone skips the Linux kernel source and downloads just what the desktop build needs:

sudo apt install -y live-build git
git clone --depth 1 --filter=blob:none --sparse --branch arena/fd4ab751-vexos \
  https://github.com/Nour-yahyaoui/vexos.git vexos
cd vexos
git sparse-checkout set distro/vexos-desktop
cd distro/vexos-desktop

2. Check, configure, and build

sh validate.sh
sudo sh auto/config
sudo sh auto/build 2>&1 | tee build.log

The result is live-image-amd64.hybrid.iso. To check progress while it runs, use this in another terminal:

grep -o '^Get:[0-9]*' build.log | tail -1

The build has finished when build.log ends with P: Saving caches.

3. Choose what goes in the image

Set VEXOS_PROFILE before auto/config:

ProfileContents
minimalTerminal only, 11 packages
desktop (default)XFCE, Firefox ESR, Python, Node.js
devDesktop plus compilers and Node.js
 
sudo VEXOS_PROFILE=minimal sh auto/config

To start over, run sudo sh auto/clean, then configure and build again. Rebuild with auto/clean after you change the package lists or the desktop settings.

VexOS Linux (terminal)

VexOS Linux is the smaller edition. It has no desktop. You log in at a shell prompt and work in bash.

  • Shell: bash, with BusyBox for the basic commands.
  • Editor: vexpad (see Tutorial 4).
  • Packages: vpk installs packages from the repositories listed in /etc/vpk/sources.list. The list is empty by default.
  • Boot: BIOS and UEFI, from the GRUB ISO. Give the VM 512 MB of RAM and one CPU at minimum.
cd distro/vexos-linux
./build.sh          # writes out/vexos-linux-1.0.iso

The kernel build is still untested, so treat VexOS Linux as work in progress.

Troubleshooting

The desktop is small and does not fill the window

Set Graphics Controller to VMSVGA and Video Memory to 128 MB in the VM settings. Then, inside the VM, open Settings > Display and pick a resolution. Guest additions for automatic resizing are not included yet.

The VM does not boot the ISO

  • Check that the ISO is attached under Storage and that the optical drive is first in the boot order.
  • Re-download the ISO and compare its SHA-256 checksum.
  • Try turning EFI off, or on, to match your choice.

The system is slow

Give the VM 4 GB of RAM and 2 CPUs. The desktop works with less, but it will be slower.

Copy and paste does not work between my computer and the VM

Clipboard sharing needs the VirtualBox guest additions, which VexOS does not include yet. Use the terminal's own copy and paste, or share files through a shared folder.

Something I installed disappeared

That is expected. The live system resets on reboot. See the note in Install in VirtualBox.

FAQ

Is VexOS a Debian distribution?

Yes. VexOS Desktop is built on Debian trixie, and the apt package manager is the standard Debian one.

Is it free?

The source is in the public repository. The Linux kernel is licensed under GPL-2.0. Check the repository for the licence of the VexOS files.

Can I install it on a real computer?

It has been tested only in VirtualBox so far. Real hardware is untested, and there is no installer yet.

Where is the source?

github.com/Nour-yahyaoui/vexos.
